## 🚀 الأنظمة المتاحة

### النظام F1: الرادار العالمي الذكي (Global Smart Radar)
**الملف**: `HajjUmrah_F1_Global_Radar_v3.json`

#### الوظيفة:
- مسح عالمي لـ 9 منصات اجتماعية
- تحليل متعدد اللغات (15+ لغة)
- تصنيف العملاء بواسطة الذكاء الاصطناعي
- نظام نقاط شرعي متقدم

#### سير العمل:
1. **Webhook Trigger**: يستقبل بيانات المسح من Apify أو جدولة زمنية
2. **Data Cleaning**: تنظيف وتوحيد البيانات (مهارة: `data-processing`)
3. **AI Legal Agent**: تحليل النوايا الشرعية (مهارة: `ai-agent-design`)
4. **Scoring & Prioritization**: تطبيق نظام النقاط الشرعي
5. **Filter High Priority**: فلترة العملاء ذوي النقاط العالية (≥70)
6. **Telegram Alert**: إشعار فوري للفريق
7. **Google Sheets**: حفظ جميع البيانات

#### معايير التقييم الشرعي:
| المعيار | النقاط |
|---------|--------|
| نيابة عن الوالدين | +20 |
| حالة وفاة + urgency عالي | +15 |
| تفاعل عالي (>100 إعجاب) | +5 |
| استفسار عام | 10-30 |
| نية شراء واضحة | 50-70 |
| ذكر تفاصيل شرعية | +10 |

## 🔧 التثبيت والإعداد

### المتطلبات:
1. خادم n8n (self-hosted أو cloud)
2. حساب Google Cloud Platform (لـ Google Sheets)
3. حساب Apify (للاستخراج من وسائل التواصل)
4. بوت Telegram (للإشعارات)
5. مفتاح API لـ OpenAI (للذكاء الاصطناعي)

### خطوات التثبيت:

1. **استنساخ المستودع**:
```bash
git clone https://github.com/your-org/n8n-hajj-umrah.git
cd n8n-hajj-umrah
```

2. **نسخ ملفات سير العمل**:
انقل ملفات `.json` من مجلد `workflows/` إلى مجلد workflows في تثبيت n8n الخاص بك.

3. **إعداد متغيرات البيئة** (.env):
```bash
GOOGLE_SHEETS_CREDENTIALS=<path-to-credentials.json>
TELEGRAM_BOT_TOKEN=<your-bot-token>
TELEGRAM_CHAT_ID=<your-chat-id>
OPENAI_API_KEY=<your-openai-key>
APIFY_API_TOKEN=<your-apify-token>
N8N_HOST=<your-n8n-domain>
```

4. **إنشاء الجداول في Google Sheets**:
- أنشئ ملف Google Sheets جديد
- أضف الأوراق (Sheets) التالية: `Leads`, `IG_Leads`, `Proxy_Requests`, `Customers`, `Campaigns`
- أضف العناوين في الصف الأول لكل ورقة

5. **استيراد سير العمل في n8n**:
- افتح n8n → Settings → Workflows → Import
- اختر ملف JSON المناسب
- قم بتحديث معرفات الأوراق (Sheet IDs) في عقد Google Sheets
- فعل الـ Webhooks والـ Schedule Triggers
